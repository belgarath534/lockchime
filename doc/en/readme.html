LockChime

LockChime plays a sound when Caps Lock, Num Lock, or Scroll Lock is turned on or off, so you always know a lock key's state without checking manually.

Features

  • Independent sound control for Caps Lock, Num Lock, and Scroll Lock
  • Separate sounds for turning a key on vs turning it off
  • Eight built-in sounds to choose from: Classic Positive, Classic Negative, Soft Positive, Soft Negative, Bell Ding, Quick Hint, Retro Coin, and Notification Ping
  • Or use your own WAV file for any on/off slot
  • Disable any key or state independently
  • Test buttons to preview each sound before saving

How to Use

  1. Open NVDA menu with NVDA+N
  2. Go to Preferences, then Settings
  3. Find the LockChime category
  4. For each key, choose a sound (or your own WAV file) for when it turns on and when it turns off
  5. Use the Test buttons to preview before saving
  6. Press OK to save
